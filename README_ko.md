<p align="center">

## 주요 기능

### 오프라인 AI

언어 모델을 안드로이드 기기에서 직접 실행합니다. 모델을 한 번 설치하면 일상적인 채팅과 글쓰기 작업을 인터넷 없이 사용할 수 있습니다.

### 범용 채팅

개념 설명, 문장 다듬기, 아이디어 브레인스토밍, 메모 요약, 번역, 코드 예시까지 폭넓게 물어볼 수 있습니다. 더 이상 여행 전용 앱이 아니라 일상 작업을 돕는 로컬 LLM 앱입니다.

### 이미지 텍스트 이해

사진을 촬영하거나 첨부하면 인식된 텍스트를 대화 컨텍스트로 사용합니다. 이미지 속 글자를 요약, 번역, 설명하거나 관련 질문에 답할 수 있습니다.

### 음성 대화

음성 입력과 TTS 출력으로 대화할 수 있습니다. Android 시스템 TTS를 쓰거나 Supertonic 3 로컬 음성 모델을 설치해 사용할 수 있습니다.

### 번역과 대면 통역

텍스트 번역 화면과 대면 통역 화면을 통해 여러 언어로 대화할 수 있습니다.

### 선택형 유틸리티

환율 변환, 간단한 지출 기록, 선택지가 필요한 질문의 버튼 응답 같은 실용 기능은 계속 사용할 수 있습니다.

## 지원 언어

- 한국어
- 영어
- 중국어
- 일본어

AI는 앱에서 설정한 언어로 대답합니다. OCR은 한국어, 영어, 중국어, 일본어 텍스트 인식을 지원합니다.

## 개인정보

- 대화용 AI 모델은 로컬에서 실행됩니다
- 채팅 내역은 기기에 저장됩니다
- 카메라 OCR은 기기 내에서 처리됩니다
- 모델 다운로드, 업데이트, 실시간 환율 조회를 선택한 경우에는 네트워크를 사용합니다

## 요구사항

- Android 8.0 이상
- 최소 RAM 4 GB
- RAM 6 GB 이상 권장
- AI 모델용 저장 공간 약 2.5 ~ 3.5 GB

## 기술 스택

- Kotlin
- Jetpack Compose
- LiteRT-LM / Gemma 온디바이스 모델
- ML Kit Text Recognition
- Room
- WorkManager
- Android TextToSpeech
- sherpa-onnx / Supertonic 3 로컬 TTS
